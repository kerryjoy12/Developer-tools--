Cookie & Local Storage Policy

Last reviewed: November 8, 2026

This page describes storage used by DevTools Hub’s own front-end code. The terms “cookie banner” and “cookie choice” are familiar interface language, but the application’s preference code currently uses browser local storage rather than setting a first-party cookie. Hosting providers and browser features operate independently and may have their own storage or technical requirements.

What this site stores

  • Consent choice: after you choose to accept or reject optional preference storage, the site records that selection in local storage so it can remember the choice.
  • Theme preference: if preference storage is accepted, toggling light/dark mode can save the selection locally. When you reject optional storage, any saved theme preference is removed.

The app does not use this storage to identify you across sites, build an advertising profile, or collect the contents entered into a developer tool. Tool inputs and outputs are not written to local storage by the current tool pages. Your browser may still remember form state, clipboard data, history, or downloaded files according to its own behavior.

Storage is not a cookie

Local storage is a browser key/value store scoped to this site’s origin. Unlike an HTTP cookie, it is not automatically attached to each request to the site. The consent and theme keys are read and written by front-end JavaScript. If the browser blocks storage or the user clears it, the choice will be forgotten and the banner can appear again. We do not control the browser’s storage implementation.

The static hosting platform receives normal network requests when pages and assets are loaded. Its security or delivery systems can process technical connection information independently of local storage. This page does not claim that every service involved in displaying a website is free of cookies or logging; it describes only the behavior configured by this site’s own app code. Check the hosting provider’s current policy for its practices.

Consent choices and changing your mind

The banner offers Allow preference storage and Reject optional storage. Either choice is saved locally so the banner does not keep interrupting you. Accepting does not enable analytics or advertising in the current site build; none are configured. Rejecting does not disable tool functionality: the conversion, formatting, and generation features remain available, although the site will use a default or system theme instead of remembering a manually selected one.

To change the choice, clear the site’s local storage in your browser’s site-data or developer-tools settings, then reload. The banner will be shown again so you can select the other option. You can also use private browsing or browser controls to limit storage, with the trade-off that preferences may not persist. Browser menus differ by vendor and release; consult the browser’s help for exact steps.

Future changes

If analytics, advertising, embedded media, or other non-essential services are enabled later, their data practices and any consent requirements will need a fresh review. The current notice is not approval for future third-party services. The related Privacy Policy explains tool input processing and hosting requests; the Terms of Service and Disclaimer describe use of the tools.
