How to Use the URL Encoder / Decoder

Step 1: Enter Your URL or Text

Type or paste a URL, query string, or any text into the input textarea. The tool handles everything from full URLs with multiple query parameters to individual path segments or plain text strings.

Step 2: Choose Encoding Mode

Select the encoding mode that matches your use case:

  • Component mode (encodeURIComponent): Encodes every special character including /, :, ?, =, and &. Use this for encoding individual URL components like query parameter values. For example, a space becomes %20 and an ampersand becomes %26.
  • Full URL mode (encodeURI): Preserves URL structural characters like :, /, ?, =, and &. Only characters that are unsafe within a URL are encoded. Use this when you have a complete URL and want to keep its structure intact while encoding unsafe characters.

Step 3: Encode or Decode

Click "Encode / Decode" to process the input. The tool automatically detects whether the input is already encoded (contains percent-encoded sequences like %20) and decodes it; otherwise it encodes it. You can also use Ctrl + Enter to trigger processing.

Step 4: Inspect and Edit Query Parameters

If the input is a URL with query parameters, the tool displays an interactive table showing each parameter name and value. You can edit parameters directly in the table, add new ones, or remove existing ones. Click "Rebuild URL" to generate a new URL from the modified parameters.

Step 5: Copy, Download, or Load Example

  • Copy Output: Copies the encoded or decoded result to your clipboard. The keyboard shortcut Ctrl + Enter processes the input.
  • Download .txt: Saves the output as a plain text file named url-output.txt.
  • Load Example: Populates the input with a realistic URL containing multiple query parameters with special characters, demonstrating both encoding modes.

Under the Hood

The URL encoder uses the browser's native encodeURIComponent() and encodeURI() functions, which implement standard percent-encoding per RFC 3986. The decoder uses decodeURIComponent() and decodeURI() respectively. The query string parser splits on & to separate parameters, then splits each parameter on the first = to separate name and value. All processing happens entirely in your browser—no URLs or data are ever uploaded to a server.

Common Errors and Fixes

"URIError: malformed URI sequence"
This occurs when trying to decode a string that contains invalid percent-encoding (e.g., %ZZ where ZZ is not a valid hex value). Ensure your encoded input uses valid hexadecimal sequences.
Output looks wrong for full URLs
If you use Component mode on a full URL, characters like /, :, and ? will be encoded, breaking the URL structure. Switch to Full URL mode to preserve the URL's structural characters.
Double encoding
If you encode already-encoded text, the percent signs themselves get encoded (%20 becomes %2520). The tool attempts to detect this and decode first, but for complex cases you may need to manually decode first.

Use Cases

  • API query building: Safely encode user-supplied search terms, filters, and parameters before constructing API URLs.
  • Debugging encoded URLs: Decode percent-encoded URLs from browser addresses, server logs, or analytics to read the original values.
  • Form data preparation: Encode individual form fields before appending them to a query string for GET requests.
  • Link sharing: Encode URLs with special characters so they work correctly in emails, social media, and chat applications.

5-Question FAQ

What's the difference between encodeURI and encodeURIComponent?

encodeURI preserves characters that have special meaning in a URL structure (:, /, ?, #, &, =). encodeURIComponent encodes almost everything including those characters. Use encodeURIComponent for individual URL components like parameter values, and encodeURI for complete URLs.

Does this handle international characters and emoji?

Yes. Both encodeURI and encodeURIComponent handle Unicode characters by encoding them as UTF-8 byte sequences with percent-encoding. For example, the character é becomes %C3%A9, and emoji are encoded as multi-byte sequences.

Can I encode a URL that's already partially encoded?

The tool attempts to detect already-encoded content and will decode it instead. However, for URLs with mixed encoded and unencoded content, you may get unexpected results. For best results, decode first if you're unsure of the current state.

Why does my encoded URL have so many percent signs?

This is normal percent-encoding. Each special character gets replaced with a % followed by two hexadecimal digits representing its byte value. For example, a space becomes %20 (ASCII 32 = 0x20). This is how URLs safely transmit characters that are not allowed in URL syntax.

Is the encoded output safe to use in a browser address bar?

Yes. The output uses standard percent-encoding that all browsers and servers understand. Copy the encoded URL directly into a browser's address bar and it will work correctly. The query parameter parser also lets you edit parameters visually and rebuild the URL.
