Privacy Policy

Last reviewed: November 8, 2026

DevTools Hub is a static website offering browser-based developer utilities. This policy describes what happens when you browse the site and use its tools. “We” refers to the people maintaining this site. The service is not designed to collect the text, code, identifiers, or files that you process with a tool.

Tool input and local processing

The JSON, HTML, CSS, Base64, URL, and UUID operations are implemented in JavaScript delivered to your browser. The tool pages do not contain a form or API request that uploads an editor’s input for conversion. When you select a file for the Base64 tool, your browser’s File API reads it locally so the page can form a data URI. When you paste from the clipboard, the browser may ask your permission. The content is displayed in the current page; the tool code does not send it to a DevTools Hub processing server.

“Processed locally” is not the same as a guarantee that information cannot leave your device by any means. Your browser, extensions, operating system, clipboard manager, network, or other software may observe activity. If you copy or download results, those results can be retained elsewhere. Do not put credentials, private customer data, or regulated information into a shared device or public screen. Clear the editor and close the tab when appropriate.

Hosting and request information

This site is configured as a static site hosted through GitHub Pages, with a custom domain listed in the repository. Loading a page necessarily sends a request to the hosting and network providers. Those providers may process connection data such as an IP address, user-agent string, requested path, timestamp, and referrer in the ordinary operation and security of their services. Their retention, regional handling, and privacy practices are governed by their own policies and terms, not by the in-browser tool code. We do not have a separate application backend or a server-side tool submission endpoint.

The pages load the site’s styles, scripts, icon, and other static assets from this site. They do not currently configure analytics, advertising tags, embedded social widgets, or third-party conversion services. If those integrations are added in the future, this policy and the consent experience should be updated before they are enabled. A deployment provider can also change the infrastructure behavior; consult the provider’s current documentation for authoritative details.

Local storage and preference choice

The shared interface offers an optional preference choice banner. Its accepted or rejected choice is saved in browser local storage under a site-specific key so the banner does not reappear on every page. If you accept preference storage, the page may also save your selected light or dark theme. If you reject, the interface removes any saved theme preference. These values stay in the browser profile and are not submitted to a DevTools Hub application server. They are browser storage, not a cookie set by this site’s tool code.

Local storage is controlled by your browser. You can clear it through the browser’s site-data controls. Private browsing, strict settings, or browser extensions may prevent it from working. The consent interface is a small preference mechanism, not a legal determination about every jurisdiction or hosting-provider technology. See the Cookie Policy for further detail.

Contact messages

The contact page currently has no operational message receiver. A clearly marked Formspree endpoint placeholder is shown for future configuration; it is not an active destination, and the sample form is disabled. Do not enter personal information there. Until the site maintainer configures and verifies a real contact channel, there is no promise that a message will be delivered or answered. See Contact for the current status.

Children, retention, and changes

The tools are general-purpose developer utilities and are not directed at children. We do not knowingly collect children’s information through an application backend, because no such backend is configured. Browser and hosting providers may process technical request data under their own services. We do not retain a server-side history of tool inputs or generated output.

We may update this policy when the site changes. The date at the top indicates the latest editorial review, not a guarantee that the host’s own policies have not changed. Important data-flow changes should be reflected here and in the page’s consent notice. The policies are informational and do not replace legal advice. If you have a question, use the contact details only when a verified channel is provided; otherwise do not submit sensitive information to the placeholder.
